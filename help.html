📇 名片管家 使用說明

拍照辨識名片、記錄拜訪、提醒跟進。資料只存在你自己的手機或電腦。

📲 1. 安裝到 iPhone 主畫面

  1. 用 Safari 打開名片管家的網址（不要用 LINE 或 Chrome 裡的瀏覽器）。
  2. 點下方中間的 分享 按鈕（方框加向上箭頭）。
  3. 往下滑，點 「加入主畫面」，再點右上角「加入」。
  4. 之後都從主畫面的 名片管家 圖示打開。打開過一次之後，沒有網路也能用。
💡 每次都從主畫面圖示打開，資料才會一直在同一個地方。用 Safari 分頁直接開網址的話，看到的是另一份資料。

🔑 2. 設定 AI（自動辨識名片用）

名片管家用你自己的 AI 帳號來讀名片。選一家申請 API 金鑰就好：

AI申請金鑰的網址說明
Claude（Anthropic）Anthropic Console中文名片辨識很準。要先儲值才能使用。
ChatGPT（OpenAI）OpenAI Platform要先儲值才能使用。跟 ChatGPT 的月費是分開算的。
Gemini（Google）Google AI Studio有免費額度，可以先試用。使用條件以 Google 的說明為準。
  1. 到上面的網站註冊，建立一組 API 金鑰（一長串英數字），然後複製起來。
  2. 打開名片管家 → 右上角 ⚙️ 設定 → 選 AI → 貼上金鑰。
  3. 按 🔌 測試連線，看到「✅ 連線成功」後按 儲存設定。
🔒 金鑰只存在你的裝置上，不會傳給任何人。不要把金鑰傳給別人，別人拿到就能用你的額度。

📸 3. 開始使用

功能怎麼用
拍一張名片按 📸 拍名片 → 拍正面（背面可不拍）→ 🤖 自動辨識 → 看一下對不對 → 儲存
一次很多張按 📚 批次 選好幾張照片。用電腦的話，也可以直接把照片拖進視窗
記錄拜訪點開一位聯絡人 → ＋ 新增紀錄，可以順便設定下次跟進日期
跟進提醒最上面會顯示「已逾期」和「7 天內跟進」的人數，點一下就只看那些人
匯出📤 匯出 → Excel、Outlook 聯絡人，或完整備份
📶 沒有網路時，查名片、寫拜訪紀錄都可以照常用。只有「自動辨識」需要網路。

☁️ 手機和電腦同步

  1. 在手機和電腦都安裝名片管家（電腦用 Chrome 或 Edge 打開網址，按網址列右邊的「安裝」圖示）。
  2. 在每台裝置打開 ⚙️ 設定 → 「用 Google 帳號開啟同步」，每台都要登入同一個 Google 帳號。
  3. 如果出現「Google 尚未驗證這個應用程式」，按「繼續」就好。
  4. 之後打開 App、修改名片時都會自動同步。上方標籤會顯示上次同步的時間，點一下可以立即同步。
🔒 資料存在你自己 Google 雲端硬碟裡一個 App 專用的隱藏資料夾，只有你看得到。Google 大約每小時會要求重新確認一次，標籤顯示「☁️ 點我同步」時點一下就好。

💾 4. 備份（很重要）

  • 資料只存在這台裝置。換手機、刪掉 App、清除 Safari 資料，名片都會不見。
  • 每個月做一次：📤 匯出 → 完整備份 → 選「儲存到檔案」，存到 iCloud 雲碟。
  • 換手機或要在電腦上用：在新裝置打開名片管家 → 📥 匯入 → 選那個備份檔。
  • 超過 30 天沒備份的話，App 會提醒你。

❓ 常見問題

  • 辨識失敗、顯示「金鑰錯誤」：到設定重新貼一次金鑰，再按「測試連線」。
  • 顯示「額度用完」：到 AI 公司的網站確認帳戶還有餘額。
  • App 有更新嗎？：有網路時打開，會在背景自動下載新版，下次打開就是新版本。
